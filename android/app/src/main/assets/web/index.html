Windows 注册表 PAC 代理注入
❌ 安卓沙盒限制无法实现。
技术根因: Android 无注册表子系统。系统网络代理必须由用户手动在 Wi-Fi 设置中输入，或通过 VpnService 启动虚拟网卡并经系统授权弹窗，无法静默注入 PAC 脚本。

桌面级物理键盘钩子与模拟键入
❌ 安卓沙盒限制无法实现。
技术根因: Win32 SetWindowsHookEx/SendInput 可全局拦截物理键盘事件。Android 为防御敲击记录器恶意木马，严禁后台全局物理键盘监听，需无障碍辅助服务且受严格权限限制。
